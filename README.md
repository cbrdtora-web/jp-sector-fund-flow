# 日本株 業種別資金流入ダッシュボード

東証プライム市場の株価・出来高から算出した「資金流入指数」を、業種別にドリルダウン
(クリックでどんどん詳しく)しながら見られるダッシュボードです。

**公開ページ:** `https://<GitHubユーザー名>.github.io/jp-sector-fund-flow/`
(GitHub Pagesの設定を有効にすると使えるようになります。下記「セットアップ」参照)

## これは何を表示しているか

- **資金流入指数**: 実際の売買代金データ(投資家が誰にいくら買った/売ったか)ではなく、
  株価の値動きと出来高から「資金の勢い」を推定した代用指標です(MFI/マネーフロー
  インデックスの考え方を応用)。値上がりした日の売買代金を+、値下がりした日を-として
  積み上げています。**投資助言ではありません。**
- **階層**: 17業種(大分類) → 33業種(中分類、ともに東証の公式分類) → テーマ
  (例:半導体、宇宙) → サブテーマ(例:メモリ、衛星の開発) → 個別銘柄。
  テーマ・サブテーマはAIが会社名から推定した近似分類で、該当銘柄が少ない
  (3銘柄未満)場合は自動的に上の階層にまとめられます。
- クリックで下の階層に進み、パンくずリストで上の階層に戻れます。個別銘柄まで
  たどり着くと、資金流入指数と株価(終値)の2つのチャートが表示されます。

## 構成

```
scripts/
  fetch_universe.py      JPXの上場銘柄一覧を取得(コード・銘柄名・33業種)
  classify_subthemes.py  33業種→17業種のマッピングとテーマ分類を付与
  fetch_prices.py        stooqから日次株価(OHLCV)を取得(初回backfill/日次update)
  compute_mfi.py         銘柄ごとの資金流入指数を計算
  build_site_data.py     ダッシュボード用のJSONを生成(docs/data/)
config/
  topix17_mapping.json   33業種→17業種の公式対応表
  subtheme_rules.json    テーマ・サブテーマ判定ルール(正規表現、AIによる近似分類)
docs/                     GitHub Pagesで公開する静的サイト本体
  index.html, app.js, style.css
  vendor/chart.umd.js     グラフ描画ライブラリ(Chart.js, CDN非依存にするため同梱)
  data/                   自動生成されるJSON(初回はまだ存在しない)
.github/workflows/
  backfill.yml            初回のみ手動実行。過去14年分をまとめて取得
  daily-update.yml        平日18:00 JST(市場終了後)に自動実行。前日分を追加取得
```

## セットアップ(このリポジトリを最初に使うとき)

1. **GitHub Pagesを有効にする**
   このリポジトリの Settings → Pages → Source を「Deploy from a branch」、
   Branch を `main` / `/docs` に設定して保存してください。
2. **初回バックフィルを実行する**
   Actions タブ → 「初回バックフィル(過去14年分の取得)」→ Run workflow。
   銘柄数が多いため完了まで1〜2時間程度かかります。完了すると自動的に
   `data/universe.csv` `data/prices/` `docs/data/` がリポジトリにコミットされ、
   数分後にPagesのページにグラフが表示されるようになります。
3. 以降は `daily-update.yml` が平日夜に自動実行され、追加のセットアップは不要です。

## 注意点・既知の制約

- **対象は東証プライム市場のみ**です(データ量を現実的な範囲に保つため)。
  スタンダード・グロース市場まで広げたい場合は `scripts/fetch_universe.py` の
  `TARGET_MARKETS` を編集してください。
- **テーマ分類は完璧ではありません。** `config/subtheme_rules.json` を編集して
  精度を上げたり、新しいテーマを追加したりできます。
- JPXの銘柄一覧ファイルのURLは将来変わる可能性があります。`fetch_universe.py`が
  失敗するようになったら、JPXサイトで最新のURLを確認してください。
- stooqのデータ取得は無料枠のため、まれに一部銘柄でデータが取得できないことが
  あります(その銘柄はその日はスキップされ、翌日以降に再取得を試みます)。
